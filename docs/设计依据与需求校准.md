## 对原需求拆解的校准

1. 外部电商并非完全没有数据来源：录音已说明存在专业供应商，具体样表仍待提供。Demo 优先展示固定维度导入方式。
2. 智能解读并未确认一定由平台 AI 自动生成。当前给出示例经营结论及可解释的情景工具，不调用模型。
3. 健康评分、权重、渗透率分母、机会模型、币种和更新频率均未在录音中逐项最终确认。保留样图示意，指标字典明确待确认。
4. 微信运营汇总与 Polartec 客户360在会议中分开讨论。集团多账号报表、标签和自动化运营不作为本 Demo 已交付的后台能力。
5. 数据中心、市场和竞品独立模板是未来扩展方向；首期使用 Polartec 大客户场景。
6. 客户原先讨论内部服务器部署；本次按用户后续明确指令交付到指定 GitHub 仓库并提供 Pages 访问。

## 重要的设计口径

- 样图金额 ¥1.2—1.8B 转为中文展示 ¥12—18 亿元；商机 ¥620M 展示 ¥6.2 亿元。
- 潜在空间、CRM 商机和单场景可获取材料收入分别展示，不能混加或当作已确认收入。
- 电商服装件数与内部材料米数不直接相减。通过适用比例和单位材料用量转换，并单独保留价格与可获取比例。
- 同一个 SKU 可能提及多种技术，竞品技术也可能功能不同，不直接视为可互相替代。
- 平台上新记录不冒充跨平台去重后的新品 SKU 总数。
- 当前企业情报卡、材料采用商品和消费者场景均为演示构造，没有真实新闻、用户引述或商品证据。

客户和周期切换；各专题导航；电商品牌/平台/品类/月度筛选；GMV/销量比较；品牌与材料详情；指标搜索；Excel 解析、导入预览、更新后指标联动；重复、负值、越界日期及客户归属校验；零适用比例时机会归零；行动完成状态；桌面与手机布局。
