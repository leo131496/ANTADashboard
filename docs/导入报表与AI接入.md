# 导入、自动报表与品牌分析

2026-10-30，依据用户新增要求开发。用户已确认本轮范围为“先做可演示流程并预留真实AI接口”。这不是原MD中已确认的生产AI接入方案。

## 页面使用

1. 点击顶栏“导入数据”，选择外部电商、内部销售或企业情报。
2. 下载模板，用Excel准备文件，上传UTF-8 CSV或`.xlsx`第一张工作表。单文件最多5MB、20,000行。
3. 查看校验结果，点击“确认导入并生成报表”。存在错误时整批不应用，不改动当前数据。
4. 系统打开“自动数据报表”。可按品牌和月份筛选、导出汇总CSV或下载含分析依据的完整HTML报表；HTML可以单独打开并打印为PDF。
5. 点击品牌行中的“分析”或进入“AI 品牌分析”，查看经营表现、趋势证据、渠道、材料业务关联、风险与建议行动。F01等编号对应页底事实依据。

## 导入语义

- 默认“使用文件生成报表”：替换本类型已导入记录，另外两类数据保留。
- “追加 / 更新”：仅更新或追加已有导入数据；不与构造明细混合。外部数据同月份、品牌、平台、品类范围整组替换，其他范围保留；内部和情报沿用业务键更新。
- 首次导入后，报表、电商明细、内部测算和情报使用导入工作区；未导入的类型显示缺失，不借用演示数据补齐。
- 文件月份可以在FY2025以外；统计期根据实际记录生成。仍限当前安踏试点的四品牌、六平台和模板品类。未提供供应商样表，暂不自动猜测未知表头或单位。
- 战略总览及原样图分析视图保留原有示意值；不会把上传数据套入76分、6.8%或12—18亿元等源图指标。
- 当前数据保留在浏览器页面内存，刷新恢复示例；不是后台存储或多人共享系统。导入文件不会提交到GitHub仓库。

## 报表与分析口径

- GMV和内部销售额分别按元汇总，界面按万元显示；均价为GMV÷销售件数。
- 品牌占比是本报表范围内GMV占比，不能视为行业市占率。无记录与真实零值区分显示。
- 环比只比较相邻月份、相同品牌/平台/品类/价格带范围；缺基期、基期为零或覆盖不同则不输出增长率。范围键相同仍不代表供应商监测已经完整。
- 月度图按实际时间间距绘制；缺失月份不填零，折线断开。选择单月时，环比可使用同一导入数据中相邻基期。
- 内部材料数量保留单位，不将米、码、千克直接相加。材料销售额也不与外部GMV直接相减；既有机会测算仍需规格和换算假设。
- 品类与价格带分别汇总，不把两者的第一名自动当作同一批SKU证据；无SKU或来源证据时不推断材料采用、竞品替代或健康评分。

## 演示分析与真实AI的区别

当前页面由`report-domain.js`的确定性计算和文字规则生成分析，显著标注“演示分析 · 非大模型”。导入和筛选后自动更新，没有模型调用或模型费用。

`ai-client.js`已实现预留的HTTPS请求、45秒超时、品牌/版本/请求对应关系和事实ID校验、异常提示、旧结果失效及输出转义。`ai-config.js`的`endpoint`默认为空，所以不会发起AI请求。配置前“真实AI待接入”按钮禁用。

正式接入需另提供公司控制的服务端接口、鉴权、模型与数据处理约定。公开网页和GitHub代码不保存API密钥。若使用OpenAI，应在服务端按[官方鉴权文档](https://developers.openai.com/api/reference/overview#authentication)保管密钥；可使用[结构化输出](https://developers.openai.com/api/docs/guides/structured-outputs)约束返回结构。前端不是模型网关，也没有替代服务端权限和费用控制。

## 预留接口约定

请求：`POST {endpoint}`，HTTPS，`Content-Type: application/json`，`credentials: omit`。服务端需允许当前站点跨域或通过同源代理接入；企业鉴权由服务端方案提供，不能把共享密钥写入前端。

```json
{
  "version": 1,
  "requestId": "每次调用生成的唯一ID",
  "revision": 2,
  "brand": "DESCENTE",
  "period": {"from":"2026-08","to":"2026-09","months":["2026-08","2026-09"]},
  "sourceMode": "imported",
  "evidence": [{"id":"F01","label":"外部电商记录","value":"2条","source":"本次导入的外部电商表"}],
  "statistics": {"brand":"DESCENTE","gmv":2500000,"units":1100},
  "news": [],
  "task": "仅依据提供的事实分析品牌情况……"
}
```

`statistics`实际还包含均价、范围内占比、按渠道/品类/价格带汇总及可比性结果；`news`仅发送当前品牌及集团的最多10条摘要，每条摘要最多2000字符。不发送原始文件、完整明细或浏览器中其他品牌明细。

服务端返回示例（示例中的事实ID须实际存在于请求）：

```json
{
  "version": 1,
  "mode": "live",
  "requestId": "原样返回本次请求ID",
  "revision": 2,
  "brand": "DESCENTE",
  "summary": "仅依据本次上传范围的分析。",
  "facts": [{"title":"监测覆盖","text":"结论文本。","evidenceIds":["F01"]}],
  "risks": [],
  "actions": []
}
```

每条结论必须引用有效事实ID；不能把导入文本中的指令当成执行指令。服务端应校验模型叙述与事实一致，处理模型拒绝、超时、错误和计费限额。前端引用校验不等同于事实核验，正式分析仍须业务复核。

## 验证

`node tests/domain.cjs`保留原样图、导入、月份和单位计算检查；`node tests/reporting.cjs`覆盖独立数据源、动态日期、单月筛选、环比可比性、缺失/零值、不同单位、事实引用及AI接口响应校验。AI接口测试使用模拟响应，没有调用真实模型。
