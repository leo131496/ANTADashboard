# 客户360看板 · 视觉精修

2026-10-30。设计对象为 Polartec 中国战略客户团队及管理层，用于安踏客户经营评审、会议投屏和后续业务沟通。沿用客户参考图的蓝白基调和A—H分析结构，应用 frontend-design 与 chart-designer 技能精修。

## 设计决策

- 深蓝 `#082C50`：导航、标题、机会总额；蓝色 `#175CD3`：交互与主趋势；纸白 `#F3F6FA`：底色；正文 `#18334C`；青绿 `#147D64`：正向增长；品牌红 `#C9253A`：少量品牌强调。
- 使用系统中文字体；主标题27—28px，模块标题15px，正文12px，辅助信息10—11px；数据采用等宽数字特性，避免数值跳动。小尺寸英文只作辅助，中文承担主信息。
- 桌面布局采用一致的边线、内距和垂直对齐。六项KPI汇成连续指标带，以深蓝突出潜在机会估算；高管洞察以细蓝顶线强调。
- 中等宽度以两列显示分析模块，避免缩小文字硬塞三列；手机单列显示，指标两列，保留全部菜单和内容。
- 图表减少淡灰文字，保留单位、图例、双轴说明和缺失数据提示；恢复/保留附件B图“按图示约值重绘、单位待确认”的限制，不给示意数据增加精度。
- 移除三张增长KPI中重复的装饰折线，避免被误读为实际月度数据；真实分析曲线和数值不变。
- 提供明确键盘焦点和减少动态效果的系统偏好支持；打印样式继续沿用原有报告布局。

```text
┌ 导航 ┐ ┌ 页面位置 / 数据口径 / 导出 ──────────────┐
│品牌  │ │ 标题                         客户 / 周期 │
│客户  │ │ 客户信息 / 报告时间                     │
│分析  │ │ 健康 / 销售 / 品类 / 新品 / 渗透 / 机会 │
│情报  │ │ A 高管洞察  │ B 经营趋势 │ C 品牌机会  │
│数据  │ │ D 技术位置  │ E 客户商机 │ F 消费信号  │
│      │ │ G 经营风险          │ H 建议行动        │
└──────┘ └ 示例数据及报告周期说明 ─────────────────┘
```

本轮为展示层调整，不改变此前核对的源数据、等级、计算公式、数据导入规则或业务范围。页面仍为交互演示，未接入真实业务系统。

## 本轮验证

- 检查1920×1080会议屏、1366×900笔记本、1024×768中等屏幕、390×844手机的布局；十个页面完成桌面与手机菜单导航检查，未出现整页横向溢出。
- 复核电商品牌筛选、无记录月份、重置，以及手机端指标字典弹窗；米/码切换的机会金额保持一致。
- 运行现有领域检查，样图数据、导入边界、月份对齐、单位转换与机会测算检查通过。
