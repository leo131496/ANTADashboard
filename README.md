# Polartec · Strategic Customer 360

美利肯战略客户经营看板交互 Demo。根据客户样图、需求拆解及 96 分 22 秒会议录音设计。

访问地址：https://leo131496.github.io/ANTADashboard/

**所有业务数值、客户评分、商品、情报、商机及关系均为设计示意。没有接入真实业务数据或 AI 服务。**

## 演示内容

- 战略总览：六项经营指标、A—H 八个区块，延续客户的深蓝品牌色与一屏决策结构。
- 经营健康、产品品类、消费者信号、材料技术、客户关系与商机、增长机会六个专题。
- 电商经营：GMV、销售件数、成交均价、平台上新记录；品牌、平台、品类及月份筛选，趋势及横向比较。
- 机会测算：将终端服装件数通过适用比例和单件用量换算为材料米数，再与内部销量对照；支持调整假设。
- 企业与竞品情报：按财报、组织、战略、材料分类，展示情报与经营模块之间的关系。当前为结构示例，没有真实新闻或原文链接。
- 数据更新中心：支持读取 `.xlsx` 第一张工作表或 UTF-8 CSV；预览、字段校验、重复检测、同键更新及增量追加。
- 客户与报告周期切换、品牌和材料下钻、指标字典、行动清单、CSV 导出、打印/保存 PDF、会议展示模式、手机菜单。

## 数据导入

在“数据更新中心”下载模板，使用 Excel 打开并编辑。模板为 UTF-8 CSV，也可另存为 `.xlsx` 再导入。

固定表头：`月份、品牌、平台、品类、GMV（元）、销量（件）、上新SKU数`。

以“客户 + 月份 + 品牌 + 平台 + 品类”为唯一键；同键覆盖，其他月份保留。文件存在错误时整批不应用。只接受当前集团与报告周期内的数据。具体平台和品类名称见模板及电商页。

导入数据、测算假设及行动状态只保留在本次浏览器会话，刷新后恢复示例。未建立后台、账号权限或持久化存储。

## 运行与发布

仓库根目录为完整静态网站，不依赖外部 CDN。直接打开 `index.html` 或使用静态服务器。

GitHub Pages 使用 `main` 分支根目录发布；`.nojekyll` 保证静态资源直接交付。原始录音、逐字转写和本地处理脚本不包含在公开仓库中。

JSZip 仅用于本地读取 Excel 压缩包，版权许可见 `JSZip-LICENSE.txt`。
