# Polartec · Strategic Customer 360

[在线演示](https://leo131496.github.io/ANTADashboard/) · [逐项需求核对与修正记录](docs/需求核对与修正记录.md)

根据客户样图、需求拆解及96:22会议录音设计。**样图中的业务数字本身就是示意；当前未接入真实业务系统、采集服务或AI。**

## 内容边界

- **样图复现**：安踏集团、2024.04—2025.03周期；六项KPI及A—H区块；品牌渗透按原图“中/低”等级展示。
- **录音补充**：电商GMV与件数、六个平台分别比较、价格带、内部销量走势、内外部同月份对照、分类企业情报及原文链接、按月数据追加。
- **演示提案**：导入表头、价格带划分、材料换算假设、行动排期。页面明确标识，不能作为客户已确认方案。
- **待确认**：健康评分模型、精确SKU分母、机会估算模型、真实数据、更新频率、AI责任、权限和生产部署。

只配置材料中出现的安踏集团和四个品牌。其他KA保留模板入口但不编造数据，不预设第二财年。

## 交互

战略总览、经营健康、电商经营、产品品类、消费者信号、材料技术、客户关系、企业情报、增长行动和数据更新共10个视图。支持品牌/平台/品类/月度/价格带筛选、品牌与材料详情、指标字典、行动状态、CSV导出、打印/保存PDF和手机菜单。

总览六项KPI保留样图示意值，不会被下方构造数据导入自动改写。其他页面的明细、趋势和机会计算使用本次会话数据。

## 导入与月度追加

数据更新中心提供外部电商、内部销售、企业情报三类Excel可用CSV模板；可读取UTF-8 CSV或`.xlsx`第一张工作表。表头仅为演示提案，待收到实际样表后映射。

| 类型 | 演示字段 | 更新规则 |
|---|---|---|
| 外部电商 | 月份、品牌、平台、品类、GMV（元）、销量（件）、上新SKU数、价格带 | 同月份/品牌/平台/品类整组替换，须包含该范围全部价格带行；其他范围保留 |
| 内部销售 | 月份、品牌、品类、材料技术、销量、单位、销售额（元） | 同月份/品牌/品类/技术更新；单位变更替换原记录 |
| 企业情报 | 发布日期、品牌、分类、标题、摘要、来源、原文链接、经营启示 | 同日期/品牌/分类/标题/链接更新；来源须为HTTPS，不自动核验 |

存在校验错误时整批不应用。外部价格带字段缺失时记为“未分价位”，不由均价推测分布；同范围不可混合汇总与价格带明细。平台分别填写天猫、淘宝、抖音、京东、快手、拼多多。

初始内外部构造数据截至2025.02，便于演示追加3月。先追加外部3月时，该月因缺内部记录不参与机会测算；再追加内部3月后才参与。无记录不等于零销量。

服装件数先经适用比例和单件材料用量转换，再与同单位内部销量对比。米/码可换算；千克与长度没有规格依据时不混算。初始内部销量独立构造，不由外部销量倒算。

**导入数据、测算假设及行动状态仅保留在本次浏览器会话，刷新恢复示例。**尚未提供服务端存储、账号权限、定时刷新或真实接口。

## 运行与发布

完整静态网页，不依赖外部CDN。可直接打开`index.html`，或使用静态服务器。GitHub Pages使用`main`分支根目录和`.nojekyll`发布。

验证：`node tests/domain.cjs`。覆盖样图数值、范围边界、平台/场景、三类导入、价格带整组覆盖、重复与异常校验、月份对齐、单位转换及机会边界。

原始录音、逐字转写和本地处理脚本未放入公开仓库。JSZip仅用于在浏览器读取Excel，许可见`JSZip-LICENSE.txt`。
